## 改了哪些

### 1. 默认时序变快（Windows）

| 项目 | 原来 | 现在 |
| --- | --- | --- |
| 开机后首次检查 | 20 秒 | **8 秒** |
| 检测间隔 | 每 1 分钟 | **每 15 秒** |
| 失败退避 | 2/5/15/30 分钟 | **30 秒 → 60 秒（封顶 60 秒）** |

掉线后基本 15 秒内就能恢复。退避封顶 60 秒，学校临时故障时也不会等上半小时。
日志里不足 1 分钟的等待现在按秒显示（原来会四舍五入成"1 分钟后再试"）。

### 2. 纯 HTTP 模式的密码存储更安全了

纯 HTTP 模式（也就是默认模式）现在把密码交给 **Windows DPAPI** 加密保存：
只有当前 Windows 用户能解开，复制到别的机器、或者换个 Windows 用户都用不了
（浏览器模式一直就是这么做的）。

更早版本保存的 `secret.json` 会在下次读取时**自动升级到加密格式**，不用重新输密码。

### 3. 连续失败会提醒你

以前密码改了、账号被别的设备占满并发数时，工具只会安静地一直失败，
你只会觉得"怎么又没网"。

现在**连续失败 3 次**（约一两分钟）会弹一条 Windows 通知，说清楚可能的原因。
失败一次成功一次就重新计数，不会反复打扰。想关掉：
`config.json` 里把 `notify_after_failures` 改成 `0`。

### 4. 日志和存档不再无限增长

改成每 15 秒一轮之后，日志和失败时存的页面/截图涨得更快。现在：

- `campus_http.log` 用滚动日志（默认每个 1MB、留 3 份）
- 失败时存档的页面 `http-*.html` 只留最近 30 份
- 浏览器模式的截图也只留最近 30 张

保留策略都能在 `config.json` 里调（`log_max_kb` / `log_backups` /
`page_dump_keep` / `screenshot_keep`）。

### 5. 计划任务改成常驻看门狗

以前计划任务是"每 15 秒拉起一个 Python 进程跑一次"，进程启动开销被放大了 4 倍。
现在改成**登录 Windows 8 秒后启动一个常驻进程**，15 秒一轮在进程内部循环：

- `MultipleInstancesPolicy=IgnoreNew` + 每 15 秒的重复触发 = 进程挂了 15 秒内被拉起，
  活着的时候不会重复启动
- 副作用（好的那种）：改完 `config.json`、或者重新设过密码，**不用重启**就生效
- 和 macOS（launchd）、OpenWrt（procd）的做法终于一致了

另外安装程序现在**建完任务会再查一次**，确认真的注册成功才告诉你"已开启"；
卸载时会先结束那个常驻进程再删任务（不然它会一直跑）。

### 6. 新增：路由器 C++ 版（aarch64）

`openwrt-cpp/` 是同一套登录逻辑的 C++ 重写：静态二进制 421KB、常驻内存 0.5MB，
原来 Python 版是 8MB 闪存 + 28~48MB 内存 —— 对闪存/内存紧张的路由器很关键。

和 Python 版的包**可以同时挂**：配置和账号文件两边通用，装哪个都能跑，
也可以随时换回来。文件名带 `aarch64` 是为了让用户一眼看出架构限制
（小米 AX3000T / MT7981 这类机器就是 aarch64）。详见
[docs/openwrt-cpp.md](../openwrt-cpp.md)。
