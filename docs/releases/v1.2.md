## 相比 v1.1 的变化

### 1. 有线网段默认改走 Dr.COM 表单（重要）

v1.1 的有线走的是学校统一身份认证，那条路要求完成一次"安全验证"：**可能是拼图滑块，
也可能是人脸识别**（`loginType=4`，需要真人对着摄像头，自动化做不到）。

实测（2026-09-16）确认：**Dr.COM 的登录接口并不拒绝有线客户端**，直接提交表单同样能上网。
于是 v1.2 把默认流程改成：

```
有线 / 无线 ──→ Dr.COM 门户表单（POST /eportal/?c=ACSetting&a=Login&ver=1.0）
                    ↓ 失败时自动回退
                 统一身份认证（CAS）
```

实测效果：从断网到恢复 **1 秒**，且不再有滑块/人脸识别的风险。
想改回旧行为：编辑 `config.json`，把 `wired_flow` 改成 `"cas"`。

### 2. 账号级错误立即停手

遇到「密码错误 / 需要验证码 / 在线数超出限制 / 已在线」这类提示时立刻停止重试，
并把服务器的原话写进日志——避免换接口反复试，把账号撞锁或被判定异常。

> 补充一个常见误区：`运营商账号在线数超出限制` **不是密码错误**，
> 而是该账号的同时在线会话满了（学校限制并发设备数）。旧会话在服务端会残留
> 7~10 分钟才释放，这期间新设备登录会被拒。

### 3. 新增 macOS 原生版

感谢 [@zacharyli001](https://github.com/zacharyli001) 的贡献（PR #1）。macOS 版是原生实现：

- 纯 Python 标准库，不需要 pip、不需要浏览器
- 密码存 **macOS 钥匙串**，launchd 开机自启，掉线自动重连
- 绑定物理网卡绕过 TUN 模式 VPN；自带迷你 DNS 绕过 Clash 的 fake-ip
- 支持按网段分别记录账号（不同运营商的校园 Wi-Fi 账号密码可能不同）

```bash
cd 校园网自动登录_v1.2_macOS版
sh install.sh
```

### 4. 新增两个探测工具（放在 `tools/`）

```bash
python tools/probe_wifi.py       # 看当前走哪套登录流程（不用拔网线）
python tools/probe_drcom.py      # 用假账号探测登录接口的参数格式
```
