## 相比 v1.2 的变化

### 1. Windows：新增 `--bind` 指定认证出口

**问题**：电脑同时插着网线和连着校园 WiFi 时，Windows 按接口跃点数选路——网线的跃点通常更低。
如果网线那头是路由器（且已经被别的账号认证过），打开登录页会直接显示"已登录"，
根本轮不到 WiFi 那份账号。

**解决**：`--bind` 把请求绑定到指定网卡的源地址发出，**只影响这个程序自己发的请求**，
不动系统路由表、不影响别的软件：

```sh
python campus_http.py --login --bind wifi        # 让认证走无线
python campus_http.py --login --bind 10.54.89.230 # 也可以直接给本机地址
python campus_http.py --probe --bind wifi         # 只想看门户认为你是谁
```

写 `wifi` / `auto` / `无线` 会自动找无线网卡（先看网卡名，再按校园无线网段 `10.52~10.63` 猜）；
写具体 IP 会先校验它是不是本机地址，不是的话把所有本机地址列出来。

### 2. Windows：在线判断容纳 3xx

`http://www.baidu.com/` 返回的是 **302 跳转 HTTPS**。绑定出口时走的是底层 `http.client`，
它不会自动跟随跳转——原来只认 200，会把"其实已经通了"误判成失败。
现在 2xx 和 3xx 都算通，只要页面或跳转地址里没有门户标记即可。

### 3. OpenWrt：一个进程管多条线路

路由器版现在可以在**同一个进程**里并行看护多条线路（每条约一个账号 / 一条上行）：

```json
"profiles": [
  {"name": "wan",  "device": "wan",       "account_type": "teacher"},
  {"name": "wanb", "device": "phy0-sta0", "account_type": "student"}
]
```

- 每条线独立目录（`profiles/<名字>/`）、独立日志、独立状态文件，日志行首带 `[线路名]`
- 一条线在登录时，另一条照常检查，互不阻塞
- **为什么是一个进程**：实测单进程 RSS 就有 24MB，而路由器只剩 20MB 出头可用，
  起两个进程装不下；一个进程里多一条线只多一个 Session 对象（约 +3~4 MB）

### 4. OpenWrt：出口绑定 + 策略路由

校园网**按终端 IP 认证**，所以每条线的认证请求必须从对应那条线出去。这中间踩了两个坑：

- `SO_BINDTODEVICE` 在无线网卡上直接报 `Host is unreachable` —— 改成"把网卡名解析成当前
  IPv4、按源地址绑定"，`SO_BINDTODEVICE` 只作兜底
- **Linux 是按目的地址选路的，光绑源地址不够** —— 脚本会自动维护策略路由
  （`from <ip> lookup <table> priority 500`，优先级排在 mwan3 的 fwmark 规则之前）

### 5. 按账号自动识别夜间限制时段

实测学校的时段限制是按**账号**分的，不是按网段：

| 账号 | 前缀 | 时段 |
| --- | --- | --- |
| 教师工号 | `M` 开头 | 所有时段都能认证 |
| 学生学号 | `B` 开头 | 只有周六日 24 小时可用，非周六日 00:00–06:00 无法认证 |

所以**一般不用手动设账号类型**：抄起一个 `M` 开头的工号，脚本自动按教师模式跑，半夜也照常重连。
手动设置（`--mode`）优先级更高。

### 6. 两条线的取舍：主备比负载均衡划算

实测（8 连接、同站点、20 秒）：

| 配置 | 合计 |
| --- | --- |
| 只走快线 | 75.5 Mbps |
| 两条线负载均衡 | **78.3 Mbps**（只多 4%）|

增益这么小是因为两条线都从同一台宿舍 AP 出去、共用那段上行。所以更适合**主备**：
平时全走快线（满速、无干扰），快线挂了自动切过去。

mwan3 默认参数下故障切换要 **110 秒**（实测），调成 `interval=3 / timeout=2 / down=2 / up=2`
后 **21 秒**。

## 通用改进

- **在线数超限等账号级问题直接停手**：不再换接口硬撞，避免账号被锁
- 日志按大小滚动、页面存档只留最近 30 份（路由器闪存小）
- 安装脚本补全依赖：`python3-logging`、`python3-codecs`
  （缺后者会连带 `unicodedata`/`idna` 不可用，导致**所有网络请求失败**）
