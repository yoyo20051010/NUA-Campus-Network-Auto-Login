首个公开版本。南京艺术学院校园网自动登录工具，Windows 与 OpenWrt 双平台。

## 下载哪个

| 文件 | 大小 | 适用 | 说明 |
| --- | --- | --- | --- |
| `NUA-Campus-Network-Auto-Login_v1.1_standard.zip` | 12.7 MB | **推荐** | 自带 Python 运行环境，纯 HTTP 模式，登录耗时 < 1 秒 |
| `NUA-Campus-Network-Auto-Login_v1.1_with-browser.zip` | 49.5 MB | 需要浏览器模式时 | 额外内置 playwright，兼容性最好 |

解压后双击 **`AAA一键安装.bat`**，按向导输入校园网账号密码即可，无需安装任何东西。

## 功能

- **开机自动登录**：登录 Windows 20 秒后检查一次，之后每分钟一次
- **掉线自动重连**：断网后 1 分钟内恢复
- **两套认证流程都已实测通过**
  - 有线（10.12.x）：统一身份认证 + 拼图滑块
  - 校园无线（10.54.x）：Dr.COM 门户表单，无滑块
- **不乱试密码**：只有「校园网认证页能打开」且「当前确实未认证」时才动作；
  连家里 WiFi、手机热点或 VPN 时直接跳过
- **夜间免打扰**：默认周一~周五 00:00–06:00 完全不尝试，也不发任何请求
- **失败退避**：登录失败按 2/5/15/30 分钟放慢重试，日志不会被刷屏
- **密码只存本机**：Windows 用 DPAPI 加密（浏览器模式）或本地文件（HTTP 模式），不上传

## 环境要求

- Windows 10 / 11（自带运行环境，**无需安装 Python**）
- 或路由器版：见仓库 `openwrt/` 目录（需要能装 Python 的 OpenWrt 设备）

## 说明

- 本工具只是替你完成你自己本来就要做的登录动作，不修改认证结果、不绕过认证。
- 请自行确认使用方式符合学校网络管理规定。
- 详细原理见 [docs/技术细节.md](../技术细节.md)。
