============================================================
  校园网自动登录  使用说明
============================================================

一句话：装好之后，开机就连网，掉线自动重连，
        不用再手动打开网页、输账号密码、拖滑块。

本安装包自带运行环境，你不需要装 Python，也不需要装任何组件。
适用系统：Windows 10 / 11（64 位）。更老的系统（Win7 / 32 位）没有实测过，
          自带的是 64 位运行环境，不保证能用。


------------------------------------------------------------
一、怎么装（大约 1 分钟）
------------------------------------------------------------

1. 把压缩包【完整解压】到任意位置（比如桌面）
   注意：不要直接在压缩包里双击运行

2. 双击    AAA一键安装.bat

3. 按屏幕提示走完，中途会让你输入校园网账号和密码

装完立刻生效，不需要重启电脑。

提示：解压后会有几千个小文件，那是自带的运行环境，属正常现象。
      用 Bandizip 或 7-zip 解压会快一些。


------------------------------------------------------------
二、安装向导会问你什么
------------------------------------------------------------

第 1 步  检查运行环境
         自动使用包里自带的运行环境，你不用做任何事。

第 2 步  选择登录方式
         [1] 纯 HTTP 模式  ← 推荐，直接回车
             不开浏览器，直接用网络请求登录，实测不到 1 秒完成。
         [2] 浏览器模式
             像人一样打开 Edge 操作登录页面，兼容性更好，
             首次需要联网下载约 40MB 组件。

第 3 步  输入校园网账号和密码
         密码只保存在本机，仅用于自动登录。

第 4 步  是否开机自动运行
         直接回车 = 开启（推荐）。


------------------------------------------------------------
三、装好之后的表现
------------------------------------------------------------

· 登录 Windows 8 秒后自动检查一次，之后每 15 秒检查一次
· 发现"在校园网但没登录"就自动完成登录
· 已经在线时什么都不做，不会反复登录
· 连家里 WiFi、手机热点、或走 VPN 时，不会去试密码


------------------------------------------------------------
四、有线网和校园无线是两套不同的登录页（工具会自动判断）
------------------------------------------------------------

  连接方式                     工具怎么做
  --------------------------   ----------------------------------
  有线（网线，IP 10.12.x）     填账号密码 → 提交 → 拖动拼图滑块
  校园无线（WiFi，10.54.x）    填账号密码提交（没有拼图滑块）

判断依据来自门户自己的规则（它看客户端 IP 决定跳哪套），
所以不需要你手动切换。

想确认当前会走哪一套，可以运行：

    runtime\python.exe campus_http.py --probe

两套流程都已经实测通过：有线走统一认证 + 拼图滑块，
校园无线走门户自己的表单（默认"校园用户"即可，通常没有滑块）。

说明：如果哪天校园无线弹出【图形验证码】（扭曲字母那种，很少见），
      纯 HTTP 模式无法自动识别，这时改用浏览器模式即可
      （重新运行 AAA一键安装.bat，选 [2]）。


------------------------------------------------------------
五、怎么确认它在工作
------------------------------------------------------------

打开文件夹里的 logs 目录：

  campus_http.log    纯 HTTP 模式的运行记录
  campus_login.log   浏览器模式的运行记录

脚本只在【状态发生变化】时写日志，所以平时日志很安静，
这是正常的，不代表没运行。

手动检查当前状态：

    runtime\python.exe campus_http.py --check

会输出三种结果之一：

    已在线             正常
    未认证/已断网      需要登录（脚本会自动处理）
    不在校园网环境     没连校园网，跳过


------------------------------------------------------------
六、不想要了怎么办
------------------------------------------------------------

双击   卸载.bat

会删除开机自启任务，并询问你是否一并删除保存的密码。


------------------------------------------------------------
七、几件要知道的事
------------------------------------------------------------

【关于密码安全】
  密码只保存在这台电脑上，两种模式都用 Windows 自带加密（DPAPI）保存，
  只有你这台电脑的这个 Windows 用户能解开。
  复制到别的电脑上、或者换个 Windows 用户，都不能直接用。
  千万不要把 secret.json 或 secret.bin 发给别人。
  （更早版本保存的 secret.json 会在升级后自动变成加密格式。）

【关于晚上 12 点断网】
  这是学校的账号策略，脚本改变不了。断网后脚本会在 15 秒内
  自动重连，但学生账号能不能在半夜重新认证，取决于学校策略。

  不过脚本已经做了对应处理：**默认周一~周五 00:00-06:00 这段时间
  完全不尝试登录**（因为学生账号本来就连不上），也不会产生任何网络
  请求和日志，早上 6 点后自动恢复常规检查。

  这个时间段可以在 config.json 里改（quiet_hours 那段）：
    enabled = false       关掉这个功能
    days = [0,1,2,3,4]    0=周一 … 6=周日；想每天都有就删掉这一行

【关于反复失败的打扰】
  如果登录失败了（比如学校临时维护），脚本不会每 15 秒死磕：
  会按 30 秒 → 60 秒逐渐放慢重试（最长 60 秒），
  一旦成功就立刻恢复常规检查。

【关于学校的注销功能】
  南艺目前的统一认证注销接口是坏的（返回"Radius注销失败"），
  你会发现自己无法主动断开校园网会话。这是学校的服务端故障，
  和本工具无关。

【会不会违规】
  本工具只是替你完成"你自己本来就要做的登录动作"，
  不修改认证结果，也不共享给他人。
  但仍建议自行确认是否符合学校网络管理规定。


------------------------------------------------------------
八、转发给同学时注意
------------------------------------------------------------

· 每个同学各自运行一次 AAA一键安装.bat，账号密码各存各的
· 不要把带密码的 secret.json / secret.bin 发出去
· 转发前建议删掉 logs 和 screenshots 目录


------------------------------------------------------------
九、出问题了
------------------------------------------------------------

先看同目录的 【常见问题.txt】。
还想深入排查，可以手动跑一次并查看过程：

    runtime\python.exe campus_http.py --login

失败时 logs 目录里会自动保存当时的页面，方便定位问题。
